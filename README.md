
#  Personal Expense Tracker

##  About the Project
Personal Expense Tracker is a Python-based desktop application designed to help users manage their daily income and expenses.

## Technologies Used
- Python
- Tkinter
- SQLite
- CSV

## Features
- Add income and expenses
- Update transactions
- Delete transactions
- Automatic balance calculation
- Category-based filtering
- Monthly expense summary
- Export transactions to CSV
- SQLite database storage
